# Ahmed Hassan Sayed — Full Stack Developer Portfolio

A frontend-only React + Vite portfolio presenting Ahmed as a Full Stack Developer with a backend focus. The content is based on the current CV and verified repository / deployment details.

## Live portfolio

https://ahmed-frontp.vercel.app

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Portfolio sections

- Overview and professional summary
- About and education
- Selected projects with working links where available
- Backend, database, frontend, and AI-related skills
- Services and practical project timeline
- CV / resume (print or save as PDF)
- Contact details and social profiles
